# v0.5.2 — 이미지 복구와 플레이 흐름 개선

## 수정
- 실제 WebP 파일과 코드의 PNG 확장자 불일치를 수정. 지도 3장, 주요 인물 4명, 시설 배경 연결 복구.
- 원격 raw URL 의존을 줄이고 저장소 상대 경로 사용. 이미지 실패 시 로컬 대체 이미지로 한 번만 처리.
- 새 배경 12장: 서쪽 숲, 시장, 벌목지, 채석장, 프로스트벨, 카르문, 엘로디아, 야외 유적, 강변 농장, 늪, 화산 계곡, 야영지.
- 기본 프롬프트: Production wide 16:9 isekai fantasy RPG background, detailed painterly anime environment, rich textures, restrained cinematic lighting, central navigable space, no text/UI/watermark. 각 장소의 건축·기후·자연환경을 개별 지정. 내장 이미지 생성 사용. 프로젝트 자산: `assets/scenes/*.webp`.
- 첫 정찰 의뢰를 수락/정찰/보고/완료 상태로 분리. 비전투 정찰 지원, 보고 시 30G와 길드 공헌 20을 1회 지급.
- 길드와 마을에서 서쪽 숲 직접 이동. 목표 패널에 현재 단계와 목적지 바로가기 추가.
- 선택지 5개 절단 제거. 야영지 모닥불, 리엔 마력 흔적, 길드 승급, 동료 편성, 상단 접근 복구.
- NPC 대화 순서/종료 관리. 주요 의뢰 상태와 날짜 변화에 따라 다시 대화. 같은 날 대화 신뢰 보상 1회 제한.
- 같은 무기 중복 구매 방지, 교체 장비 가방 보관.
- 시스템 결과가 시설 인사말에 가려지던 표시 문제 수정. 방문 인사 순환.
- 기존 `anotherWorldV04Draft` 저장 호환. 새 저장키 `anotherWorldV052` 사용, 기존 키는 보존. 자동 저장과 시작 화면 이어하기 추가.
- 모바일 화면, 스크롤 가능한 선택지, 키보드 포커스, M 지도/Esc 닫기 개선.

## 검증
`node tests/regression.cjs`: 18개 게임 상태 회귀 검사. 실제 게임 스크립트를 VM과 최소 DOM 모형에서 실행. 브라우저 렌더 검사를 대신하지 않음.

모든 현재 장소/초상화/지도 자산 경로의 파일 존재 검사 포함. 첫 의뢰 무전투 완료, 중복 보상 방지, 대화 종료, 기존 저장 변환, 야영지 탈출, 전투 후 보고 대기 상태를 확인.

## 범위
지역별 장소들은 어울리는 배경을 공유할 수 있음. 기존 전투 밸런스 및 전체 후반부 콘텐츠를 새로 작성한 버전은 아님. NPC 대화는 상태 기반으로 작성된 대사이며 실시간 생성형 AI 호출을 추가하지 않았음.

## 이어서 완료한 QA 보완
- 기존 생성 배경 12장과 주요 초상화 4장 재사용. 이미지 재생성 없음.
- PC 3영역 배치: 좌측 정보 탭, 중앙 큰 인물/배경 및 하단 대사, 우측 행동. 기록은 접기 제공.
- HP/MP/피로/허기/수분/레벨/XP/골드 상시 표시. 시간 경과에 따른 허기·수분 변화와 식사·수분 회복 연결.
- 여관 숙박은 동료 포함 HP/MP 및 피로 회복, 아침 식사 포함. 무료 우물 휴식과 하루 2회 여관 일손 돕기로 초반 빈곤/패배 복구 가능.
- 무기 상점에 판매 중/보유 중/장착 중 표시, 소유 및 골드 부족 구매 버튼 비활성화. 생활 도구 중복 구매 방지.
- 장비 공격력/방어력, 레벨, 무기 숙련, 마나 제어, 속성 숙련·약점·저항, 컨디션, 난수가 전투에 반영. 특기 2턴 재사용 대기. 주문 사용 시 숙련 증가.
- 적 능력치가 피해에 반영되지 않던 문제, 패배 뒤 종료된 전투를 참조하던 오류, 다른 동료도 리엔으로 표시되던 문제 수정.
- 로컬 DOM 흐름 검사: 시작 → 등록 → 수락 → 정찰 → 보고 → 대화 종료 → 저장/불러오기 → 지도 → 여관 식사/숙박 → 상점 구매/보유 표시 → 숲 전투 → 마을 회복.

## 남은 범위
- 후반 지역 전체 전투 밸런스는 장시간 플레이 검증이 필요함.
- 일부 보조 인물/적은 기존 SVG 일러스트를 사용함. 글자가 포함된 SVG text 요소는 없음.
- 동종 환경의 여러 장소가 같은 배경을 공유함. 낯선 숲길과 서쪽 숲도 같은 새 숲 배경 사용.
