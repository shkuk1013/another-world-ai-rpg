# Another World v0.5.1 VISUAL REBUILD

사용자가 승인한 생성 이미지를 실제 게임 자산으로 반영한 테스트 빌드.

## 반영 완료 자산
- 알테라 대륙 판타지 지도
- 브렌 지방 상세 판타지 지도
- 사냥터 성장 흐름 지도
- 브렌 마을 전경
- 모험가 길드 내부
- 황금사슴 여관 내부
- 대장간 내부
- 마법/연금술 공방
- 미라 대화 초상화
- 에밀리아 대화 초상화
- 브람 대화 초상화
- 리엔 대화 초상화

## 대화 UI
대화용 캐릭터 이미지는 이름/직업/스펙 텍스트가 없는 초상화 이미지로만 사용.
왼쪽 장면 위 오른쪽에 큰 초상화 카드로 노출하고 중앙 패널 하단에 대사 선택지를 배치.
캐릭터 상세 스펙과 배경은 관계/도감 영역에서 분리.

## 지도
M키에서 별도 제작된 이미지 지도 사용. 현재 위치 마커만 HTML UI로 오버레이. 미구현 지역은 이미지 자체의 안개 영역으로 유지.

GitHub에는 아직 반영하지 않았습니다.
