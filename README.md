# Another World AI RPG

살아있는 이세계 판타지 RPG를 목표로 만드는 웹 프로토타입입니다.

## 현재 버전
Prototype v0.2

### 구현된 기능
- 캐릭터 생성 / 초기 성향
- F급 모험가 길드 등록
- 검 / 단검 / 활 / 지팡이
- 무기별 숙련도
- 체력 / 마나 / 피로 / 골드 / 평판
- 브렌 마을, 모험가 길드, 대장간, 마법 상점, 여관, 훈련장, 서쪽 숲
- 장비 구매
- 마법 습득 / 직접 마법 연구
- 고블린 전투
- 퀘스트 / 보상
- 브라우저 로컬 저장

## 프로젝트 방향
단순 생존 게임이 아니라, 이세계 애니처럼 사람과 관계를 맺고 마법을 배우며 세계 안에서 살아가는 감정을 목표로 합니다.

### 앞으로 추가할 핵심
- 전투 거리 / 자세 / 스킬 / 상태이상 / 적 패턴
- NPC 초상화 / 지역 배경 / 몬스터 일러스트
- 동료와 개인 서사
- NPC 장기 기억
- AI 자유대화
- AI 게임마스터와 세계 사건 시뮬레이션
- 속성·형태·변형 룬 기반 마법 조합
- 장비 희귀도 / 랜덤 옵션
- 길드 승급 및 여러 지역
