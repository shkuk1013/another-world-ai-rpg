# Another World AI RPG

살아있는 이세계 판타지 RPG를 목표로 만드는 웹 프로토타입입니다.

## 현재 버전
**Prototype v0.3**

## v0.3 핵심 변경
- 전투 거리 시스템: 원거리 / 중거리 / 근거리
- 적 행동 예고(Intent)
- 무기별 유효 거리
- 검 / 단검 / 활 / 지팡이별 전술 스킬
- 방어 / 접근 / 거리 벌리기 / 도주
- 화상 상태이상
- 적 방어 자세
- 패배 후 NPC 반응 이벤트
- 첫 위험 의뢰 완료 시 감정 연출
- 장면 배경 이미지 영역 추가
- 대화 로그에 NPC/몬스터 초상화 표시
- 브렌 마을 / 미라 / 리엔 / 고블린 기본 비주얼 추가

## 현재 구현된 성장

## 프로젝트 방향
단순 생존게임이 아니라,
**이세계 애니처럼 사람과 관계를 맺고, 약한 모험가에서 시작해 마법을 배우고 동료와 성장하며 세계 속에서 실제로 살아가는 감정**을 목표로 합니다.

## Asset folders
- `assets/portraits/` — NPC 초상화
- `assets/backgrounds/` — 지역 및 이벤트 배경
- `assets/enemies/` — 몬스터 일러스트
- `assets/items/` — 무기·장비 아이콘
- `data/` — NPC / 퀘스트 / 세계 데이터
